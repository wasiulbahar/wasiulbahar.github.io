# wasiulbahar.github.io

Personal website of **Wasiul Bahar** — photojournalist, multimedia journalist at Nutshell Today, and open-knowledge organizer from Dhaka, Bangladesh.

- `index.html` — overview: fields of work, current roles, experience, awards
- `photography.html` — photo portfolio with filters and lightbox
- `writing.html` — articles and publications featuring my photographs

Plain HTML/CSS/JS, served by GitHub Pages. To add a photo, drop the full image in `img/gallery/`, a ~900px copy in `img/thumbs/`, and add a `<figure>` to `photography.html`.
